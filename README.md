# Event Management System

This repository contains the software engineering documentation for the Event Management System.

## Documents Included

- IEEE Software Test Plan
- 10 functional, non-functional and security test cases
- Security validation plan
- Requirements Traceability Matrix
- Software Architecture and Design Specification
- Component diagram and description
- UML sequence diagrams
- API design
- Error-handling design

## Project Status

This repository currently covers the requirements, testing, architecture and design phases. Source-code implementation has not yet been developed.
